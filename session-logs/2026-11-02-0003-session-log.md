## Limitations And Scope

- This is a local comparison experiment, not an exact StoryMaps implementation.
  The globe footprint connects projected view corners with spherical segments;
  it is a locator approximation, not an analytical boundary.
- Later sections supersede the experiment's original center and navigation
  behavior. Regional defaults and airport anchors are now configurable;
  pan limits and the existing default overview navigation remain unchanged.
  Ocean-only views between islands remain possible and intentional.
- Five small WebGL renderers are added in trial mode. Physical mobile-device
  performance and long-running resource use have not been certified.
- Existing remote background/state layer failures, SDK deprecations and large
  bundle warnings remain. npm reported the same 18 audit findings after install
  (4 low, 2 moderate, 12 high); no audit fixes were applied.
