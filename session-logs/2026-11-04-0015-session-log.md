- [Reproducible sizing probe](../experiments/storymaps-embed-sizes.mjs)

Default inline URL embeds use a nominal 16:9 fallback for Small, Medium, and
Large. Their width choices differ; a height cap of 91% of available application
height can change the actual ratio. Custom/source dimensions can override the
fallback. Sidecar media fills its available panel and has no fixed aspect ratio.
Docked narrative widths can produce near-square or portrait iframe viewports.
Floating/slideshow narrative overlays require separate host-level checks.

The handoff records actual iframe CSS-pixel dimensions for eight placements at
three host sizes: 1280x720, 1920x1080, and 2560x1600. It separates measured
StoryMaps geometry from map-fit acceptance and flags portrait cases as an
extension to the existing landscape-only ADR scope. No map-fit tests or
application behavior were changed by this agent.
