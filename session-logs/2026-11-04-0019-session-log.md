## Branch and Implementation

Created `experiment/vt-basemaps` from clean local `main`, both initially at
`4f3b43c500433d6baf3a952506d6df7a1e42cae2`. The prior
`prototype/webmap-canvas` branch is untouched. Main did not yet contain
`src/projections.js`; this experiment brings over that shared definition file,
independently compared with the committed prototype. This includes the requested
Alaska Albers meridian -154, rather than main's older -146. No single-canvas
renderer, experiment dependencies or prototype entry points were brought over.
`AGENTS.md` and `.github/copilot-instructions.md` were unavailable in this repo.

- `webmap=<ID>` replaces hard-coded operational layers in all seven panes.
  Every pane owns a separate Map and separate cloned operational layers.
  Native WebMap loading preserves renderers, filters, visibility, nested layer
  IDs and other SDK layer properties. Without `webmap`, the original layer
  membership remains, including overview-only graticules.
- One collapsed main-view Layer List controls visibility across every pane by
  web-map layer ID. Visibility also carries into panes created later.
- `basemaps=conus:<ID>,ak:<ID>,hi:<ID>` accepts a Web Map's basemap or a vector
  tile item. Each base/reference layer is loaded and its actual
  `tileInfo.spatialReference` checked before any views start. Mixed tile CRSs,
  unknown WKIDs, non-vector basemap layers and mismatched projection numbers
  are refused with visible diagnostics, not replaced silently.
- Numeric checks cover Albers method, central meridian, origin, both parallels,
  false easting/northing, meter units and Greenwich degree coordinates. NAD83
  and WGS84 are allowed, with datum differences noted. WKT uses `wkt-parser`
  1.5.5; known WKID numbers were cross-checked with registry exports.
- `overviewBasemap=conus` uses a separate clone of the CONUS basemap and its
  tile CRS. Its former overview center is reprojected. Without that option,
  the existing overview projection and framing remain.
- Lambert ignores both basemap URL options with an on-page message. The
  operational `webmap` option still works. `overviewBasemap=co` in the truncated
  request was interpreted as the explicitly documented `overviewBasemap=conus`;
  `co` itself is not a supported alias.
- Tile views disable LOD snapping, preserving continuous linked scales and
  existing responsive framing. Optional SDK classes load dynamically to stay
  within the existing main-chunk budget. No budget was raised.

## Shoreline Measurements

Exact scales were asserted after cross-frame scale synchronization. Measurements
use native MapView screenshots of a 200x200 CSS-pixel crop: basemap only, then
the unchanged `United States and Outlying Areas` renderer only. Other operational
layers are temporarily hidden for measurement, then all visibility is restored.
The selected operational edge is nearest the crop center; the reported distance
is to the nearest basemap edge. Alpha below 128 is excluded. Antialiasing, stroke
width and integer-pixel sampling imply roughly 1px uncertainty. These are named
samples, **not maximum errors over every coastline or every operational layer**.

Sample WGS84 locations: Seattle (-122.3575, 47.621), Key West (-81.81, 24.552),
Anchorage (-149.918, 61.218), Honolulu (-157.866, 21.305). Both overview modes

The datum-only comparison projects the same numeric lon/lat labeled WGS84 versus
NAD83 into the tile CRS using the SDK. Differences are Seattle 1.287m, Key West
0.573m, Anchorage 1.247m and Honolulu 1.551m. This distinguishes a datum effect
from observed cartographic differences; it does not establish survey accuracy,
an epoch-specific transformation, or the operation selected by every service.
The numeric datum displacement is far smaller than the visible Hawaii discrepancy.

Hawaii advertises bounds approximately 160.248W..154.767W, 18.9059N..22.2397N;
the native tile extent is x=-338056.5489..232461.773,
y=656999.3312..1022046.6091 in ESRI:102007. It covers the main islands, not the
northwestern chain (e.g. Midway/Kure). Its style draws land only: surrounding ocean
and areas beyond that coverage remain transparent/white. The captured Hawaii
close-up requests only use `tile/0/0/0.pbf`, despite 19 advertised LODs and style
maxzoom 18. Coarse, angular land boundaries visibly diverge from the operational
shoreline, including around Honolulu. This basemap is **not accepted as detailed
coastline parity**. No attempt was made to invent missing detail or alter its style.
