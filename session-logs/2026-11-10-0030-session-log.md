## Trial and Decision

The trial collected the strongest segment coverage in one single-channel R8
texture using MAX blending, then composited the stroke color once per symbol
group. It replaced stencil-based first-segment selection and used a stable
pixel-width estimate for antialiasing. Normal and multiply outlines shared the
same reusable texture/framebuffer; no new context or depth/stencil buffer was
created. A follow-up discarded zero-coverage composite pixels.

All 384 synthetic cases passed: DPR 1/2, widths 0.25/0.5/1 point, eight
fractional pixel phases, joined/unsplit segments, duplicate features, alpha
1/0.5 and normal/multiply paths. Maximum mean-width relative error was 1.266%
at DPR 1 and 0.376% at DPR 2; minimum coverage ratio was 98.734%. These sampled
straight-line checks are not complete native border/join/projection fidelity.

The high-density frame-cadence regression repeated in the initial trial, the
empty-pixel-discard trial and the complete final measurement. Therefore this
implementation is **not accepted**. The predeclared gates were not relaxed.
Only this session's renderer changes were removed, with `cmp` establishing byte
equality to the isolated committed baseline. No R8 buffer remains in the app.
Existing border defects are not fixed by this delivery.
